# Icon

The bundled icon was generated using the built-in image-generation tool, then resized for Xcode and Safari assets. It is a companion to the existing RegexDojo palette.

Prompt: “Create a polished square iOS app icon for DevTools. Artwork only, no lettering. Center a luminous silver-white gear around a navy terminal >_ symbol. Use midnight navy, blue/cyan edging, violet mountain contours and a restrained pink sunset accent. Keep the mark legible at small sizes. Full-bleed opaque square; no device mockup, inset frame, outer rounded-square border, white margin or watermark.”

The 1024px opaque app icon is in App/Assets.xcassets/AppIcon.appiconset. The final asset is embedded in the project and does not depend on an external image URL.
